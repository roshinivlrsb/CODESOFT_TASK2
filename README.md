# PhishGuard - Phishing Awareness Program

## Cybersecurity Internship — Task 2

This project is a phishing awareness website designed to educate users about phishing attacks and online safety.

## Features

- Phishing awareness tips
- Online safety guidelines
- Quick phishing quiz
- Interactive correct and incorrect answer feedback
- Responsive website design

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The purpose of this project is to help users identify suspicious messages and avoid phishing attacks by following safe online practices.
